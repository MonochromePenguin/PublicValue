# PublicValue
PublicValueプラグインは、専用の映像エフェクトで設定した値を、アニメーションタイプから呼び出せるようにするプラグインです。<br>
※このプラグインを利用することによる不具合や不都合などに対しては自己責任でお願いします。

## 使い方
- 値の設定
  - 映像エフェクト内にある「値の共有」映像エフェクトを追加します。
    - エフェクトを付けたアイテムの処理タイミングによって動作が変化することがあるため、出来るだけ上のほうのレイヤーに配置することをお勧めします。
  - 「キー」にプロジェクト内で一意の小数を設定します。
  - 任意の値及びアニメーションを設定します。
    - Math.Clamp( 係数 * ( Main + Main2 ) + Value1 + Value2, 値制限の基準値 - 値制限の範囲, 値制限の基準値 + 値制限の範囲 ) の値がキーに設定されます
  - 必要に応じて「値の終了」トグルを有効にします。
    - 「値の終了」を有効にすると、そのアイテムが終わった後に過去の値としてアクセスできなくなります。
- 値の利用
  - YMM標準の「アニメーションを設定」ボタンをクリックして、その中に現れる「共有数値を参照」を選択します。
  - 二つのスライダーのうちの下の方に、先ほど設定した「キー」と等しい値を入力することで、キーの値を利用できます。
  - 上のスライダーの数値に応じて、過去の値を利用できます。
    - マイナス値は非対応です。
    - 「現在のフレーム - 値」フレーム時点の値を利用します。
  - 適応するエフェクトによっては値の上限や下限に触れて、キーなどの値を適切に設定できないことがあります。

## 既知の問題
### 未修正の問題
- 特定条件で場面切り替えアイテムを使用するとプレビューがクラッシュする
- シーク時に正常にプレビューが更新されないことがある

### 修正された問題
- 動画出力時、値の共有を開始したフレームのみ、遅延エフェクトに該当の値が反映されない
  - v1.0.1で修正
